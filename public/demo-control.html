Recommended 10-minute presentation flow

Start with the Nexus homepage and explain the four pillars: discovery, scoring, community and commerce.
Use Browser 1 as Admin and show real RBAC-protected administration.
Use Browser 2 as User and create a review/comment or vote.
Switch back to Admin and demonstrate moderation / role management.
Return to User and show creator discovery, wishlist, cart and simulated checkout.
Finish by opening the project documentation and showing the AI prompt-driven development process.
Important: Nexus authentication, payment and external integrations are prototype/demo implementations. Present them honestly as such. The goal is to demonstrate a functioning university-scale system and the AI-assisted engineering process, not production deployment.
